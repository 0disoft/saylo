# Saylo 0.1.0

Stable release for `@0disoft/saylo-core`, `@0disoft/saylo-react`,
`@0disoft/saylo-svelte`, `@0disoft/saylo-typegen` and `@0disoft/saylo-vite`, using
the npm `latest` tag. All five packages and their internal dependencies use
`0.1.0`. Vue remains a private workspace package.

## Included changes

- Generated rich text tag contracts and optional strict renderer maps.
- Live pseudo-localization that preserves ICU arguments and rich tags.
- Optional development schema recovery for required-argument additions and
  deleted keys, with strict rendering retained as the default.
- Automatic key selection follows wildcard reexports, including barrel chains,
  cycles and configured aliases, and retains keys in production bundles.
- Migration detects private method parameter shadowing rather than rewriting
  ordinary callbacks.
- Review drafts, selection and unsaved state survive edits made while refresh
  or search responses are pending; the original revision still protects saves.
- Incremental lazy development subscriptions replace repeated full-scope sends.
  See [scaling measurements](../docs/lazy-scope-scaling.md).
- Bounded second-chance formatter admission reduces cyclic cache misses without
  increasing the 256-entry message cache limits. See
  [measurements and the below-capacity tradeoff](../docs/formatter-cache.md).
- Installation guides and initializer commands use the stable channel.

## Install

```sh
npm install @0disoft/saylo-core
npm install -D @0disoft/saylo-vite @0disoft/saylo-typegen vite@8
```

For a reproducible selection of this release, use `@0.1.0` on each Saylo package.
Update the Vite server and client together: incremental subscription messages
require the matching server. Existing full-scope clients remain supported.

## Validation and publication

The [release workflow](../.github/workflows/release.yml) runs against committed
`main` with `version=0.1.0`, `dist_tag=latest`, `verify_oidc=true` and
`publish=true`. It verifies release metadata and OIDC, installs the lockfile,
audits dependencies, runs the full workspace check, builds and tests the actual
five tarballs in independent consumers, then publishes those verified artifacts.
There is one validation-and-publication run rather than separate dry-run and
publication runs. A failed preceding step prevents publication.

The workflow run and its `saylo-npm-0.1.0` artifact are the publication evidence;
the artifact contains `manifest.json` with package names, versions and SHA-512
integrities. These notes describe the release scope and do not themselves attest
to a successful registry write. Historical alpha.9 artifact records remain in
[its manifest](0.1.0-alpha.9.json).
