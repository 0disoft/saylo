# 0.1.0-alpha.5 release

Release target: 2026-10-25, five public packages, npm dist-tag `alpha`. Publication is pending; CI and registry verification will be recorded here after completion. The `latest` tag is not changed. Vue remains a private workspace at alpha.4 and is excluded from publication.

## Changes

- Rich text parts in core and React/Svelte rendering helpers, with tag allowlists and SSR support.
- Shared project configuration, catalog checks, translation export/import/refresh, and optional review approval records.
- Synchronization state and support diagnostics, with bounded diagnostic records and no automatic upload.
- Optional cancellation and injected runtime operations, bounded catalog-loading concurrency, safer temporary-file cleanup, and isolation of late completions.
- Automatic key analysis and lazy catalog push fixes, indexed catalog lookups, and large-catalog update optimizations.
- English READMEs and developer documentation, including the 13-document Vite installation bundle.
- Updated the development-only undici dependency to 8.12.3; the dependency audit reports zero vulnerabilities.

## Verification

Local verification passed: `npm run audit:dependencies` (zero vulnerabilities), `npm run check` (563 tests in eight groups, zero failures, and consumer type checks), `npm run release:check -- --version 0.1.0-alpha.5 --tag alpha`, `npm run release:pack` (all five tarballs installed into independent JS/checkJs and TS apps, README examples, CLI workflow, rich text, synchronization/support contracts, SSR, watcher/WebSocket push, and Vite production builds), the publication dry run, and `npm run verify:docs`. The CI run, approved artifact integrity, and registry consumption results will be appended after execution. Earlier frozen candidates remain historical evidence in the [release plan](0.1.0-alpha.5-plan.md).
