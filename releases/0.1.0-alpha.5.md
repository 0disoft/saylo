# 0.1.0-alpha.5 release

Published on 2026-10-25: five public packages, npm dist-tag `alpha`. [CI run 40126424440](https://github.com/0disoft/saylo/actions/runs/40126424440) published all five packages from source `745d3204165a4582eae022826a848398e24c6503`, with all release steps passing in 1 minute 30 seconds. The `latest` tag is not changed. Vue remains a private workspace at alpha.4 and is excluded from publication.

## Changes

- Rich text parts in core and React/Svelte rendering helpers, with tag allowlists and SSR support.
- Shared project configuration, catalog checks, translation export/import/refresh, and optional review approval records.
- Synchronization state and support diagnostics, with bounded diagnostic records and no automatic upload.
- Optional cancellation and injected runtime operations, bounded catalog-loading concurrency, safer temporary-file cleanup, and isolation of late completions.
- Automatic key analysis and lazy catalog push fixes, indexed catalog lookups, and large-catalog update optimizations.
- English READMEs and developer documentation, including the 13-document Vite installation bundle.
- Updated the development-only undici dependency to 8.12.3; the dependency audit reports zero vulnerabilities.
