# 0.1.0-alpha.8 release

Published on 2026-10-26: all five public packages under dist-tag `alpha`. [CI release](https://github.com/0disoft/saylo/actions/runs/40217372424) published source `3d6b2b2ac9c036e0171046236baa32929cf1a8dc`. Vue remains private at `0.1.0-alpha.4`; its internal core dependency follows alpha.8.

## Changes

- Add isolated React and complete SvelteKit initialization presets.
- Add optional missing-key and formatting-error callbacks, and explicit message fallback locale chains. Strict exceptions remain the default.
- Add translation metadata, reviewer attribution, Gettext PO exchange with portable escaped UTF-8 handling, and an authenticated loopback review UI with bounded request admission and cancellation.
- Add i18next directory migration and guarded rewriting of static translation call keys.
- Add opt-in catalog cache budgets with indexed eviction that avoids rescanning protected boot scopes.
- Share the physical catalog I/O concurrency budget across SSR stale retries, including sources that ignore cancellation.
- Align Vite release locale checks with CLI configuration and include the new workflow guides in installation documentation.

Existing translator, store and framework call signatures remain compatible. New runtime policies, fallback chains and cache budgets are opt-in. The review UI is local tooling; reviewer names provide audit context rather than identity proof.

## Verification

Local `npm run check` passed 647 checks across package boundaries, runtime suites and release helpers, plus consumer type checks. Dependency auditing found no vulnerabilities. A Linux CI admission test initially exposed a client/server synchronization assumption; it now waits for HTTP 100 Continue before asserting saturation and observes server-side recovery after disconnects. The corrected review-server suite passed locally and the complete release workflow passed before publication.

CI verified OIDC exchange for all five packages, locked dependency auditing, runtime and consumer checks, independent tarball consumption and publication. All five npm `alpha` tags resolve to alpha.8. Independently downloaded registry tarballs match every SHA-512 value in the [CI-approved manifest](0.1.0-alpha.8.json).
