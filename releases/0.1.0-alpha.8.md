# 0.1.0-alpha.8 release

Prepared on 2026-10-26 for the five public packages under dist-tag `alpha`. Publication and registry verification are pending. Vue remains private at `0.1.0-alpha.4`; its internal core dependency follows alpha.8.

## Changes

- Add isolated React and complete SvelteKit initialization presets.
- Add optional missing-key and formatting-error callbacks, and explicit message fallback locale chains. Strict exceptions remain the default.
- Add translation metadata, reviewer attribution, Gettext PO exchange with portable escaped UTF-8 handling, and an authenticated loopback review UI with bounded request admission and cancellation.
- Add i18next directory migration and guarded rewriting of static translation call keys.
- Add opt-in catalog cache budgets with indexed eviction that avoids rescanning protected boot scopes.
- Share the physical catalog I/O concurrency budget across SSR stale retries, including sources that ignore cancellation.
- Align Vite release locale checks with CLI configuration and include the new workflow guides in installation documentation.

Existing translator, store and framework call signatures remain compatible. New runtime policies, fallback chains and cache budgets are opt-in. The review UI is local tooling; reviewer names provide audit context rather than identity proof.

## Verification

Validation is in progress. The release workflow must pass dependency auditing, runtime tests, consumer type checks and independent tarball consumption before publishing.
