# 0.1.0-alpha.7 release

Published on 2026-10-25: all five public packages under dist-tag `alpha`. [CI run 40187216309](https://github.com/0disoft/saylo/actions/runs/40187216309) published source `1a4b253d5615a90627f8c75056eb94d837212c65` in 1 minute 33 seconds. Vue remains private at `0.1.0-alpha.4`; its internal core dependency follows alpha.7.

## Changes

- Add `saylo init` integration for existing Vite apps and validated i18next JSON-v4 migration.
- Compact production catalogs and SSR boot payloads when the encoded output reduces transfer size.
- Preserve Svelte block translator aliases during automatic key selection and parse components with the app's Svelte compiler.
- Isolate published translator snapshots from mutable caller catalogs.
- Reuse immutable manifest identity and catalog signatures to avoid repeated serialization during refresh and eager locale switches.

Existing translator, store, and Svelte binding call signatures remain compatible with alpha.6. Existing applications receive catalog compaction through their production build without changing translation calls.
