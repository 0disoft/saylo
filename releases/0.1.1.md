# Saylo 0.1.1

Published on 2026-11-18 for core, React, Svelte, Vue, typegen and Vite under `latest`.
All six packages and their internal dependencies use `0.1.1`. Version `0.1.0`
already exists for the original five packages and is not overwritten.

## Included changes

- First public Vue 3 adapter release, including snapshot-bound stores and selectors,
  request-local SSR, rich text rendering and generated strict renderer types.
- Vue joins candidate promotion, release metadata, artifact integrity checks,
  OIDC authentication and independent JS/TS package consumption.
- Literal text bypasses formatter caches, reducing formatter construction and
  message-key serialization for that path.
- Automatic production key analysis rejects unscanned relative code imports
  before silently removing their translation keys.
- Live catalog saves check a remembered base-file witness before a full rescan.

The simple-message AOT compiler remains a benchmark experiment; this release
does not enable a new production compiler backend.

## Publication and verification

The release workflow runs on committed `main` with `version=0.1.1`,
`dist_tag=latest`, `verify_oidc=true` and `publish=true`. It checks all six
package-scoped OIDC exchanges, release metadata, dependency audits, tests,
consumer types and independently installed tarballs before publication.

The successful [release run 44150361355](https://github.com/0disoft/saylo/actions/runs/44150361355)
used source `4b9e7bf9a278130d45676460d2481f5f2b25e4da`. Its
`saylo-npm-0.1.1` artifact supplies the [approved SHA-512 manifest](0.1.1.json).
All six downloaded registry tarballs match that manifest and have `latest=0.1.1`.
`npm run verify:registry:stable` passed independent JS/checkJs and TypeScript
installs, CLI and README examples, Vue concurrent SSR and escaped rich text,
React/Svelte SSR, runtime/support contracts and production Vite lazy builds.

All six Trusted Publishers authenticated for `0disoft/saylo`, `release.yml`,
environment `npm-release`, with publication allowed. Core, React and Svelte
were published by [attempt 44147500031](https://github.com/0disoft/saylo/actions/runs/44147500031),
which then stopped because Vue's registration stage reserved the same version.
Vue was published by manually approving that stage; its bytes match both CI
artifacts, but this first Vue release has no provenance attestation. The final
successful run skipped those four identical versions and published typegen and
Vite. The other five packages have registry provenance attestations. No version
was overwritten or unpublished.

The release initially stopped at the dependency audit. A temporary private
[picomatch security fork](../vendor/picomatch/PATCH.md), committed as `62f1a57`,
guards single-branch repeated wildcards in release tooling. The SvelteKit
example was updated to kit 3.3.0 and adapter-node 6.0.4 in `4b9e7bf`.
Both lockfile audits report zero vulnerabilities without an advisory allowlist.
The example also passed its security tests, zero-error/zero-warning typecheck,
client/SSR builds, concurrent SSR and production adapter HTTP verification.
The fork is excluded from published artifacts and should be removed when an
upstream fix becomes available.
