# 0.1.0-alpha.6 release

Prepared on 2026-10-25 for publication. The five public packages (`@0disoft/saylo-core`, `@0disoft/saylo-react`, `@0disoft/saylo-svelte`, `@0disoft/saylo-typegen`, and `@0disoft/saylo-vite`) will be promoted together to `0.1.0-alpha.6` under dist-tag `alpha`. `latest` remains unchanged. Vue remains a private workspace at `0.1.0-alpha.4`; only its `@0disoft/saylo-core` dependency will be updated.

Publication is pending verification by the main agent. This record does not claim that the packages have been published, that the full release checks have passed, or that CI-approved artifacts exist. The final CI URL and the five artifact integrities will be recorded after publication.

## Changes

The only behavioral delta since alpha.5 fixes a false Vite warning. `hotUpdate` previously inferred a direct JSON import from `modules.length`, so watcher-only `EnvironmentModuleNode`s for CSS or Tailwind with `id: null` could emit `Managed catalog is directly imported`. The check now requires a non-null resolved ID and a file path that matches a managed catalog.

Direct imports of catalog JSON, `?raw`, and `?url` continue to report the warning. Watcher-only modules no longer do. HMR and on-screen state preservation are unchanged.

## Verification

The regression was reproduced with real Vite module nodes before the fix. After the change, all 57 targeted plugin/server tests passed. The source fix is `4cdf148`.

These targeted results do not establish release acceptance. Source release scripts will validate the entire five-package cohort later. After publication, `npm run verify:registry:alpha6` and `npm run verify:registry:sveltekit:alpha6` will check the approved registry artifacts; the full release result will be recorded here then.
