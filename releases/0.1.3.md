# Saylo 0.1.3

Published on 2026-11-18 under `latest` for core, React, Svelte, Vue, typegen and Vite. The core catalog loader checks elapsed time before starting queued I/O and before accepting a result. When the event loop delays the timer callback, expired work still reports `TIMEOUT`, and late results stay out of the cache.

[Release workflow 44271238605](https://github.com/0disoft/saylo/actions/runs/44271238605) built and published all six packages through npm Trusted Publishing from source commit `8c91ad18c0fb0f5a91795e7ce354c5d887fc63fc`. It passed all six OIDC exchanges, both dependency audits, runtime and consumer type checks, and independent JavaScript and TypeScript installs of the packed artifacts. The Vue fixture passed concurrent SSR and escaped rich text checks.

All six npm `latest` tags point to `0.1.3`. Each SLSA provenance statement names the release workflow, source commit and run, and its SHA-512 digest matches the [approved CI manifest](0.1.3.json).

Some registry endpoints initially returned HTTP 404 before the attestations and tarballs became available. The subsequent `npm run verify:registry:stable` run downloaded all six packages, matched their SHA-512 digests to the approved manifest, and passed independent JavaScript and TypeScript consumption, including Vue SSR and escaped rich text.
